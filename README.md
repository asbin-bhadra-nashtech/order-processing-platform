# Order Processing Platform

A simple order processing platform built as a hands-on DevOps and Cloud Engineering assignment.

## Services

- Order API
- Order Processor
- Notification Service

## Technology

- Java 21
- Spring Boot
- Docker
- Kubernetes
- Helm
- Terraform
- Azure AKS
- Azure Container Registry
- GitHub Actions
